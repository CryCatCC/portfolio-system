# Токени дизайн-системи (затверджений мінімальний набір)

Звід з `docs/tokens-draft.md` за правилами курсу. Сира чернетка зі значеннями з Figma лишається в `tokens-draft.md`.

Позначки: **макет** (значення з Figma, у т. ч. оцінене на око), **запропоновано** (на макеті немає).

## Кольори (7 ролей)

| токен | hex | звідки |
|---|---|---|
| canvas | `#F3F3F3` | макет |
| surface | `#FFFFFF` | запропоновано |
| line | `#D8D4CE` | макет (колір закладок), роль запропонована |
| accent | `#0F3659` | макет, роль підтверджена |
| ink | `#101010` | макет |
| ink-muted | `#666666` | макет |
| danger | `#B42318` | запропоновано (відтінок 4°, accent 208°) |

Не стають токенами: `#B0264D` і `#383838` (кольори закладок проєктів), `#F5F5F0` (зведено до canvas), `#402F2F` (зведено до ink), палітра обкладинки (це зображення).

Текст на accent: `canvas`. Кнопка Let's talk на макеті: фон `ink`, текст `canvas`.

## Текст

Шрифт один: **Inter**, підмножини latin і cyrillic. Roboto Condensed і IBM Plex Mono лише в обкладинці, у систему не входять.

| токен | розмір / рядок | жирність | трекінг | що зведено |
|---|---|---|---|---|
| caption | 11 / 16 | 400 | 0,09em | футери (10), мітки закладок (10,5) |
| label | 13 / 20 | 500 | 0 | ENG/UA (13), лого (14) |
| button | 11 / 16, великі літери | 500 | 0,12em | Open portfolio, Let's talk, eyebrow (12) |
| body | 15 / 24 | 400 | 0 | абзац (15 / 165 %) |
| lead | 18 / 28 | 400 | 0 | запропоновано, на макеті немає |
| heading | 28 / 36 | 500 | −0,02em | запропоновано, на макеті немає |
| display | 38 / 45 | 400 | −0,05em | заголовок героя (38 / 119 % / −1,8 px) |

Разом 7 розмірів (ліміт 9). Дрібний текст обкладинки (8–9 px) не входить.

## Радіуси

| токен | значення |
|---|---|
| control | 0 px (кнопки) |
| card | 0 px (прямі кути на макеті) |

Закладки з верхніми кутами 4 px (оцінено на око) зведено до 0. Круглі соцкнопки 40 px роблю через `rounded-full`, окремого токена немає. Скажіть, якщо хочете інакше.

## Пропорції картинок

| токен | значення | звідки |
|---|---|---|
| cover-magazine | 7 / 10 | макет (обкладинка 420×600) |
| cover | 3 / 2 | запропоновано (обкладинка проєкту в картці) |

## Відступи (5 кроків)

8, 12, 16, 24, 32 px.

Зведено: 4 → 8, 23 → 24, 50 → 32. Макет: 12 (eyebrow до заголовка), 16 (соцкнопки), 24 (заголовок до абзацу).

## Розміри макета (не відступи)

| що | значення | звідки |
|---|---|---|
| ширина контенту | 1050 px | макет |
| проміжок між текстом і обкладинкою | 166 px | макет |
| відстань між великими секціями | 96 px | запропоновано |

## Контраст (за формулою WebAIM)

| пара | контраст | |
|---|---|---|
| ink на canvas | 17,15 | ✓ |
| ink-muted на canvas | 5,17 | ✓ |
| ink-muted на surface | 5,74 | ✓ |
| canvas на accent (текст кнопки) | 11,18 | ✓ |
| danger на canvas | 5,92 | ✓ |
| danger на surface | 6,57 | ✓ |
| межа поля форми: ink-muted на canvas | 5,17 | ✓ (≥ 3) |

`ink` на `accent` дає 1,53, тому текст на accent не ink. `line` на canvas 1,33: тільки для декоративних ліній.
